# ツボマップ3D

回しながら見られる人体図（皮膚・筋肉・骨）に、自分のツボを打って、名前と説明を残せるアプリです。
ツボを見られるのは、管理者が許可した人だけです。許可された人には「見るだけの人」と「編集もできる人」がいます。

## ログイン

- 管理者が、見せたい人のメールアドレスを「メンバー」に追加します。
- 追加された人は、アプリの「はじめての方（登録）」から、そのメールアドレスとパスワードを登録します。
  届いた確認メールのリンクを開くと、ログインして見られるようになります。
- 管理者が「メンバー」で「取り消し」を押すと、その人は見られなくなります。

## 使い方

- **ツボを打つ**（編集できる人だけ）：「ツボを打つ」（鉛筆のボタン）を押してから、体の表面をタップします。名前と説明を入れて「保存」。
  ペンを使っている間も、ドラッグすれば図は回せます。
- **見る**：図の上のタグ（ツボ名）か、一覧の「詳細」を押すと、説明が出ます。
  同時に、そのツボを打ったときの画面（向き・近さ・透け具合・部位）に戻ります。体の表面のツボは、見る角度によって下の筋肉や骨とずれて見えるためです。
  回したあとは、説明の「打ったときの画面に戻す」で戻せます。画面を覚え直すときは「編集」→「いまの画面を、このツボの見え方として記憶」。「編集」から名前・説明の変更、位置の打ち直し、削除ができます。
- **表示のオン・オフ**：一覧のツボ名を押すと、そのツボの表示を切り替えられます。「すべて表示」「すべて隠す」もあります。
- **寸を測る**（編集できる人だけ）：「寸を測る」（ものさしのボタン）を押してから、体の表面の2点をタップします（ツボのタグも選べます）。
  2点の間を体の表面に沿って測り、その部位の骨度（例：前腕は肘横紋〜手関節横紋を12寸）で寸に直して、cm と一緒に出します。
  1寸の長さは部位ごとに違います。基準にした区間と値は `kotsudo.js` の先頭にまとめてあります。
- **図の操作**：1本指（マウスはドラッグ）で回転、2本指（マウスはホイール）で拡大、2本指のドラッグ（マウスは右ドラッグ）で移動。
  皮膚と筋肉の透け具合はスライダーで、表示する部位（体幹・腕・脚）はボタンで選べます。

## ツボの保存について

- ツボは体の表面（皮膚）に付きます。皮膚を透明にしても、同じ位置に表示されます。
- ツボは Google の Firebase（Cloud Firestore）に保存され、ログインした人の画面にすぐ反映されます。Mac と iPad の間も自動でそろいます。
- 読めるのは許可された人だけ、書けるのは管理者と「編集もできる人」だけです（Firebase 側のルールで守っています）。
- 「図に表示する・隠す」の切り替えは人それぞれなので、端末ごとに覚えます。
- 編集できる人は「書き出し」で控えのファイルを作れます。「読み込み」で戻せます。

## アプリとして入れる

- **iPad / iPhone**：Safari でこのページを開き、共有メニューから「ホーム画面に追加」
- **Mac**：Safari でこのページを開き、メニューの「ファイル」→「Dock に追加」

一度開くとモデルが端末に保存され、電波がなくても使えます。

## 注意

学習・記録用の図です。動作を軽くするため、元の3Dデータより形を簡略化しています。体表の一部は計算で改変しています。
